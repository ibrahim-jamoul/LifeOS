# 01 — Spécification fonctionnelle Religion V1

## 1. Objectif produit

Transformer la branche Religion de LifeOS en espace de **pratique, apprentissage et progression**, pas en simple dashboard.

Au lancement du module, l'utilisateur doit pouvoir :
1. savoir ce qu'il doit réellement faire aujourd'hui ;
2. lancer ou valider ses routines ;
3. enregistrer ce qu'il a réellement étudié ;
4. retrouver ce qui doit être révisé ;
5. visualiser sa progression dans le temps.

## 2. Trois axes structurants

### Coran
- objectif principal : 3 nouvelles pages par mois ;
- semaines 1 à 3 : une nouvelle page par semaine ;
- semaine 4/5 : révision et consolidation ;
- mémorisation + compréhension + Tafsir ;
- répétition régulière ;
- réutilisation en prière lorsque possible ;
- suivi des passages fragiles via **points d'attention Coran**.

### Arabe
- environ 30 minutes par jour ;
- apprentissage à partir de textes réels ;
- préférence pour les textes liés à la religion ;
- lecture avec voyelles ;
- compréhension ;
- relecture sans voyelles ;
- vocabulaire réellement rencontré ;
- écriture / copie de quelques phrases.

### Apprentissage religieux
- au minimum une chose nouvelle chaque jour ;
- Seerah : une vraie séance structurée par semaine ;
- progression complémentaire : Aqida, Fiqh, Hadith, Tafsir, Histoire, Biographies ;
- notes, enseignements, synthèses et ressources.

## 3. Routines complémentaires

- Duʿāʾ : apprentissage régulier, sens + contexte d'utilisation.
- Adhkār : apprentissage et usage contextuel.
- Dhikr : objectif quotidien personnel.
- Sadaqa : routine du vendredi.
- Lecture/apprentissage du soir : remplacer progressivement le scrolling.
- Coran : répétition quotidienne de ce qui est en cours.

## 4. Philosophie UX

Le système doit favoriser l'exécution.

À éviter :
- gros dashboard abstrait ;
- listes d'objectifs annuels dans "Aujourd'hui" ;
- saisie répétitive ;
- duplication entre Religion et les objectifs globaux ;
- statistiques omniprésentes ;
- système qui punit une journée ratée.

À privilégier :
- "Que dois-je faire aujourd'hui ?";
- bouton de démarrage rapide ;
- saisie en quelques secondes ;
- continuité d'une session à l'autre ;
- révisions remontées automatiquement ;
- vue statistique séparée.

## 5. Règle de temporalité

Une action n'apparaît dans "Aujourd'hui" que si elle est réellement prévue ce jour-là.

Exemples :
- arabe : quotidien ;
- apprentissage religieux : quotidien ;
- dhikr : quotidien ;
- sadaqa : uniquement vendredi ;
- Seerah : uniquement le jour planifié ;
- Coran approfondi/Tafsir : week-end selon programme ;
- semaine de consolidation : priorité aux révisions plutôt qu'à une nouvelle page.

## 6. Objectifs actifs V1

Ne pas multiplier les objectifs. Trois objectifs structurants :
1. Coran.
2. Arabe.
3. Apprentissage religieux quotidien.

Les autres éléments sont des routines, sessions, sujets, ressources ou indicateurs.
