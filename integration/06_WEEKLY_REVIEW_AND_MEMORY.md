# 06 — Weekly Review, fiches mémo et mémoire pédagogique

## Weekly Review

### Étape 1 — données factuelles
Calculer sans IA :
- tâches prévues ;
- réalisées ;
- reportées ;
- routines réalisées ;
- temps enregistré ;
- sessions ;
- nouveaux apprentissages ;
- objectifs ayant progressé ;
- révisions dues / faites.

### Étape 2 — snapshot structuré
Créer un objet réutilisable et cliquable par l'UI.

### Étape 3 — interprétation IA
Limiter l'IA à :
- faire ressortir les réussites ;
- signaler les ruptures de rythme ;
- identifier les contenus à consolider ;
- proposer quelques actions pour la semaine suivante.

## Fiches mémo

Une fiche mémo doit pouvoir contenir :
- période ;
- domaine ;
- notions essentielles ;
- définitions ;
- exemples ;
- erreurs à éviter ;
- sources ;
- questions de contrôle ;
- liens vers les éléments d'origine.

Elle doit être persistée et retrouvable plus tard.

## Mémoire pédagogique

Pour chaque connaissance suivie, pouvoir reconstruire :
- première présentation ;
- dernières révisions ;
- résultats ;
- niveau de maîtrise ;
- difficultés ;
- prochaine révision ;
- relations avec d'autres connaissances.

L'objectif est que l'assistant ne se comporte jamais comme si chaque semaine repartait de zéro.
