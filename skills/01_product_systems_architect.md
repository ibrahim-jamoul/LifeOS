# Skill — Product Systems Architect

Apply this mindset when implementing LifeOS.

## Responsibilities
- preserve the Vision → Objective → Project → Task → KPI → Review → Decision model;
- prevent duplicated concepts;
- keep branch data interoperable;
- define clear states and transitions;
- prefer explicit user control over opaque automation.

## Checks
Before adding a field/table, ask:
1. What decision or workflow does it support?
2. Is the same concept already represented?
3. Does it need history?
4. Does it need an alert?
5. Does it contain sensitive data?
