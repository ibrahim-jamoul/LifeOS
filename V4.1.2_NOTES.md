# LifeOS V4.1.2 — notes rapides

Objectif de cette itération : rapprocher davantage le rendu de l'esprit des visuels V4 montrés, tout en gardant les fonctionnalités existantes.

## Ajustements principaux
- Refonte visuelle du shell applicatif (sidebar + header + fond général).
- Harmonisation du design system global (`globals.css`).
- Refonte plus représentative des pages/espaces clés :
  - Aujourd’hui (conservé, compatible avec le reste)
  - Planning
  - Objectifs
  - KPI
  - Vision
  - Revue hebdomadaire
- Conservation du fonctionnement métier existant :
  - création de tâches / missions ;
  - saisie d’objectifs ;
  - saisie KPI manuelle ;
  - navigation ;
  - revue hebdomadaire ;
  - liens existants vers les modules.
