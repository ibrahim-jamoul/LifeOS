# Project Arbitration Framework

LifeOS should help expose trade-offs, not make the final decision.

## Inputs per project
- Impact: 1–5
- Urgency: 1–5
- Confidence: 1–5
- Effort: 1–5
- Deadline
- Budget
- Strategic objective
- Current status
- Next action
- Last activity

## Indicative score
`Impact × Urgency × Confidence ÷ Effort`

Example interpretation:
- higher score = potentially attractive use of resources;
- score is not a verdict;
- manual `FOCUS` remains authoritative.

## Portfolio constraints
Recommended:
- max 3 FOCUS;
- 3–5 ACTIVE;
- unlimited BACKLOG.

Warn when:
- more than 3 FOCUS;
- a project has no linked objective;
- a FOCUS project has no next task;
- no activity for 14 days;
- deadline passed;
- budget actual exceeds planned;
- multiple projects pursue the same objective with no differentiated hypothesis.

## Weekly arbitration questions
1. If I could advance only three outcomes this week, which?
2. What is consuming time without moving an objective?
3. Which project should be paused?
4. Is there a project that can be merged with another?
5. What new evidence changed my priorities?

## Stop criteria
A project should be considered for pause/cancel when:
- its objective no longer matters;
- the original assumption is disproven;
- opportunity cost becomes too high;
- there is no next test that could change the decision;
- another project achieves the same outcome more efficiently.

Log the decision in the journal.
